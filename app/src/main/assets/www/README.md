# Pocket Ledger

A small, installable money tracker for Android and other phones.

## What it does

- Record money received or spent, with an amount and date.
- Choose a spending category, or create and color your own categories.
- Review monthly spending, net income or loss, recent activity, and a circular category breakdown.
- Open a category to see its spending entries for the currently selected month.
- Choose light, green dark, gray dark, or AMOLED black appearance in Settings; choose a white, green, gray, or AMOLED logo background; set the currency and exact accent color; and reset the accent independently.
- Use the Settings install button on Android to add Pocket Ledger to the home screen. The selected logo style supplies the installed app icon.
- Choose the app language: English, Portuguese, Spanish, French, German, Italian, or Japanese. The selected language also controls date, time, and number formats.
- Export all transactions, categories, and settings to a JSON backup, then import it in another browser or on another device. Importing replaces the data currently saved there and asks for confirmation first.
- Reset the appearance or clear all activity from Settings. Clearing activity requires typing `DELETE`, removes user-created categories, and keeps the default categories and preferences.
- Choose a calendar date and time using the matching in-app pickers; each entry saves both.
- Use a one-time category label, or choose to save that label for later, for both spending and income.
- Keep using the app offline after its first successful load.

## Your data

Transactions, categories, and settings are saved in this browser on this device. They are not sent to an account or synced to other devices, so changing browsers or devices will not move them automatically. Use **Export data** in Settings before switching, then **Import data** on the other browser or device. Clearing the browser's site data also removes the local copy, so keep a backup if you want to preserve it.

## Add it to an Android home screen

This folder contains the app, but it has not been published to a web address yet. For Android installation, the folder needs to be hosted at an HTTPS address. Once it is hosted, open that address in Chrome on the phone and choose **Install app** or **Add to Home screen** from the browser menu. After the first load, the app shell is cached for offline use.

The app can also be opened as a regular web page for a quick preview. Browser installation and offline caching need a secure hosted address (or a local development server).
